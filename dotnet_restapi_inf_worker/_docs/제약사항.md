# 제약사항

- .NET 10 기반 프로젝트
- Windows Service 설치 및 실행 지원
- Windows x64 대상 Publish 지원
- PDB 디버그 정보를 포함한 Single-file 실행 파일 Publish
- `InputDataCollector.cs`: 매시 10분 REST API 호출 및 응답 데이터 PostgreSQL 저장
- `SimulationResultPublisher.cs`: PostgreSQL 시뮬레이션 결과 REST API 전송
- PostgreSQL 데이터베이스 사용
- NLog Rolling File 로그 사용
- 로그 파일당 최대 크기 5MB
- 로그 파일 최대 30개 보관
- REST API `host`, `port`, `token` 사용자 설정
- PostgreSQL `host`, `port`, `username`, `password`, `search path` 사용자 설정
- PostgreSQL 기타 연결 옵션 사용자 설정
- 기본 로그 레벨 Debug
- 애플리케이션 시작: `app start` Info 로그
- 애플리케이션 중지: `app stop` Info 로그
- 애플리케이션 Dispose: `app disposed` Info 로그
- `scripts/install.bat`: Windows Service 설치
- `scripts/uninstall.bat`: Windows Service 삭제
- Install/Uninstall 스크립트 Publish 결과물 포함
